## 教訓追記のルール

1. **1カテゴリにだけ書く**: 複数カテゴリにまたがる場合は主カテゴリにだけ書き、他からはリンクで参照する。
2. **フォーマットを守る**: 見出しは `### YYYY-MM-DD [Tag1][Tag2] タイトル` 形式。
3. **Master Rule 化の条件**: 同一カテゴリで類似教訓が3件以上 → ファイル冒頭の `## 📌 Master Rules` に集約昇格。
4. **Critical Rule 化の条件**: 本番事故直結 / 3回以上の再発 / 「これさえ守れば多くが消える」と判明 → `lessons.md` の Critical Rules 表に格上げ。
5. **削除しない**: 退役した教訓は末尾に `🗄️ Archived` 注記のみ。削除は再発防止記録を失う。

---

## 追記フォーマット

```markdown
### YYYY-MM-DD [Tag1][Tag2] 教訓のタイトル
- **❌ Anti-pattern (どんなミスをしたか):**
  具体的な状況・コード・エラーを記述。
- **✅ Solution / Rule (どうすれば防げるか):**
  再発防止のためのルールを記述。
```
