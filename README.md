# りんごちゃん薬局 シフト作成ツール

## プロジェクト概要
りんごちゃん薬局（1店舗）のスタッフ11名が、スマートフォンやPCから毎月の「希望休」を提出し、それをもとにルールベースのアルゴリズムがシフト案を自動生成するWebアプリケーション。

## 画面構成

### メイン画面（`index.html`）
- **PC**: ガントチャート形式。ドラッグで複数日一括選択して希望休を登録。
- **スマホ**: カレンダー形式。日付タップで詳細表示・登録。
- 希望休の種類に対応（休み希望 / AM可 / 終日可 / その他）
- 画面下部に「条件付き・その他の希望」リスト表示

### シフト生成画面（`generate.html`）
- 月を選択してシフトを自動生成（30パターン試行→最高スコア採用）
- Undo/Redo/Reset機能で手動調整の履歴管理
- ガントチャートで結果表示（希望休はストライプ背景で種類別に色分け）
- セルクリックで手動微調整（ドロップダウン）
- 画面下部の**条件チェックパネル**で全スタッフの制約充足状況を自動判定
- CSV出力（Shift-JIS対応）

### 管理画面（`admin.html`）
- スタッフの追加・編集（職種・区分・勤務条件を設定）
- 表示順の並び替え（▲▼ボタン）
- 有効/無効の切り替え
- 月別設定の管理
- テスト用データリセット機能

## シフト生成アルゴリズム

ルールベース貪欲法（30パターン試行→最高スコア採用）で**決定論的に**自動生成。
AI/機械学習は使用しておらず、全てのルールは明示的にコード内で定義されている。
詳細な制約条件は [`docs/shift-generation-requirements.md`](docs/shift-generation-requirements.md) を参照。

### 生成の流れ（暫定）
1. 服部・福島（常勤薬剤師）を各日に配置
2. 湯本をペース配分＋体制ルールで配置
3. スポットワーカー（堀口・財津）を不足日に配置
4. 鈴木で残りの不足を補完
5. 村上で最終穴埋め（薬剤師不足時のみ）
6. 常勤事務（野口・小野寺・笠原）を配置
7. 山口で事務1名不足日を補完

### 主要な制約（概要）
- **ハード制約**: 店舗充足、希望休反映、連勤上限、湯本の1人勤務禁止・月回数・土日重複禁止、堀口の1人勤務禁止
- **ソフト制約**: 常勤優先配置、鈴木の穴埋め、村上の出勤最小化、山口の穴埋め配置、湯本の午後中心配置
